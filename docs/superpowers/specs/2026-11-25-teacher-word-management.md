# 교사: 올린 단어 관리 (#44)

교사가 엑셀로 올린 단어를 수업별로 보고, 고치고, 지운다. 서버 API는 ssen-server develop의 `/api/teacher/classrooms/{id}/words`(조회·수정·삭제), `/chapters/{chapter}`(차시 삭제), `POST .../words?replace=true`(교체).

## 화면 (`/manage-words`)
- 진입: 내 정보의 교사 카드 `올린 단어 관리`. 접근 제한은 `/upload`와 같다(로딩 중 빈 화면, 비로그인 `/login`, 교사가 아니면 `/account`).
- 수업을 라디오 행으로 고르면 단어를 불러와 차시(Week)별로 묶어 서버 순서대로 보여 준다. 차시 제목은 `{차시} · {n}단어`, 단어 행은 `{번호}. {단어}`와 뜻(품사가 있으면 뜻 앞에).
- 수업을 바꾸면 편집·확인 상태를 모두 버리고, 늦게 온 이전 수업의 응답은 요청 번호로 무시한다.

## 수정
- 행 아래에 인라인 폼이 펼쳐진다(한 번에 하나). 입력 검증과 번호·품사·예문 활용형 이어 붙이기는 학생용 로컬 단어 폼과 같은 `src/data/wordForm.ts`의 `formFromWord`/`buildWord`를 그대로 쓴다. 학생용 `WordFormSheet`는 로컬 저장소에 묶여 있어 쓰지 않는다.
- 차시는 읽기 전용이다(서버가 원래 차시로 고정한다).
- 저장은 `PUT`의 응답으로 목록의 그 단어를 바꾼다. 같은 차시에 같은 단어가 있으면 서버가 409(`같은 단어가 이미 있어요.`)를 주고, 그 메시지를 폼 안에 보여 주며 폼은 열어 둔다. 학생 북마크는 유지된다.

## 삭제와 확인
- 단어 삭제, 차시 삭제 모두 그 자리에서 인라인 확인(`지우기`/`취소`)을 거친다. `Alert`는 웹에서 동작하지 않아서 화면 안에서 처리한다.
- 지우면 그 단어(차시 삭제는 차시의 모든 단어)를 북마크한 학생의 북마크도 함께 사라진다. 확인 문구에 이를 적는다. 차시의 마지막 단어를 지우면 차시도 목록에서 사라진다.

## 엑셀 올리기의 교체 옵션
- 미리보기 아래 `이 파일에 없는 단어는 지우기 (차시 단위로 교체)`. 기본은 꺼짐이고 파일을 다시 고르면 꺼진다.
- 켜면 `GET .../words`로 현재 단어를 불러와 지워질 단어를 계산한다: 현재 단어 중 파일에 들어 있는 차시의 단어이면서, 같은 차시의 파일 단어와 `word.trim().toLowerCase()`가 다른 것. 파일에 없는 차시는 건드리지 않는다. 서버의 `replace=true`와 같은 기준이다.
- `지워질 단어 {m}개`, 단어 목록(최대 20개, 이후 `외 N개`), 북마크 경고를 보여 준다. 올리기 버튼은 `{n}개 올리고 {m}개 지우기`가 되고 `replace=true`로 올린다. 결과는 `새로 {c}개, 고친 {u}개, 지운 {d}개를 올렸어요.`
- 현재 단어를 불러오는 동안은 올릴 수 없고, 불러오기에 실패하면 오류를 보여 주며 올리기를 막는다(교체를 끄면 올릴 수 있다). 파일·수업·토글이 바뀌면 이전 계산은 버린다.
