# 학습 흐름 개편 — Day별 홈 목록, 뜻 꾹 누르기 동의어, 예문 가리기

## 배경

2026-10-28 팀 회의에서 단어를 보는 흐름이 바뀌었다. 지금 앱은 홈에서 단어마다 큰 카드(뜻, 영영풀이, 예문, 동의어·반의어·파생어·유의어)를 펼쳐 보이고, 학습 탭은 "단어만 보이고 두 번 눌러 뜻을 펼치는" 카드다. 회의에서 정한 내용과 이후 확인한 답은 다음과 같다.

- 홈 탭: **Day별로 나눈 단어 목록**을 보여준다. 목록에서 단어를 고르면 **그 단어의 동의어와 예문이 담긴 학습 탭으로 이동**한다.
- 학습 탭: 표제어와 **표제어 뜻(여러 개)**을 보여준다. **항상 뜻이 보인다.**
- 뜻을 **꾹 누르는 동안** 그 뜻의 **동의어(영단어)**가 보이고 뜻은 가려진다. 손을 떼면 뜻이 다시 보인다.
- 단어를 누르면 **그 단어를 쓴 예문과 한국어 해석**이 보인다. 해석에서 **맥락 뜻만 가려져** 있고, 꾹 누르면 맥락 뜻이 보인다.
- **영영풀이, 반의어, 파생어, 유의어는 데이터와 화면에서 뺀다.** 동의어는 **뜻별**로 구분한다.
- 새 화면의 디자인은 아직 없다. **원본 프로토타입(`pocket-vocabulary-v2`)을 레퍼런스로 재사용**한다.
- 교사가 올리는 엑셀에는 **동의어 열 하나**를 두고, 그 뜻을 가진 영단어를 쉼표로 구분해 적는다.

## 범위

**포함**: 단어 데이터 구조 v2(와 옛 저장 데이터 변환), 단어 추가·수정 폼, 홈 Day 목록, 학습 화면, 암기 모드 정리, 서버 스펙의 단어 필드 갱신 메모.

**제외**: 서버 단어 테이블 구현과 교사 업로드(1b, 교사 회의 후 확정), 챕터 관리 화면, 나만의 단어장, 네이티브 확인.

## 데이터 구조 v2

```ts
type WordDetails = { example: string; exampleKo: string; exampleMeaning: string };

type Word = {
  id: string;
  word: string;
  meanings: string[];
  synonyms: string[];   // meanings와 같은 길이. synonyms[i]는 i번째 뜻의 동의어를 쉼표로 이은 문자열('' 허용)
  chapter: string;      // 예: 'Day 1'
  details: WordDetails; // 영어 예문, 한국어 해석, 맥락 뜻
};
```

- **빠지는 것**: `definitions`, `details.synonyms/antonyms/derived/related`, `details.definition`.
- `synonyms[i]`는 `"nurture, develop, foster"`처럼 쉼표로 이은 문자열이다. 표시할 때 쉼표로 나눠 칩으로 그린다(앞뒤 공백 제거, 빈 조각 제거).
- **옛 저장 데이터 변환**(`normalizeWord`, 저장 키 `pocket-vocab-words-v1`는 그대로): `definitions`, `details.antonyms/derived/related`는 버린다. 새 형태의 `synonyms` 배열이 있으면 뜻 개수에 맞춰 자르거나 `''`로 채워 쓰고, 없으면 옛 `details.synonyms`(단어 하나에 하나인 문자열)를 **첫 번째 뜻의 동의어**로 옮기고 나머지 뜻은 `''`다. 기존의 다른 변환(`meaning` 단수, 챕터 없음→`Day 1`, 객체가 아닌 값 거르기)은 그대로 유지한다. 저장은 다음 변경 때 새 형태로 쓰인다.
- **암기 모드 정리**: `MaskField = 'word' | 'meaning'`, `Prefs`에서 `maskDetails`를 뺀다(저장된 prefs의 옛 키는 읽을 때 무시). 일괄 정답 보기·줄별 보기 로직은 단어·뜻 두 필드만 다룬다.
- **샘플 단어 4개**는 새 구조로 다시 쓴다(원본 `app.js`의 뜻·예문·동의어 값을 뜻별로 나눠 옮긴다. 뜻이 둘 이상인 단어는 뜻마다 다른 동의어를 둔다).

## 홈 탭

레퍼런스: 원본의 **리스트 보기 카드**(`.list-mode .word-card`: 표제어 왼쪽, 뜻 오른쪽, 오른쪽 끝 수정·삭제 아이콘)와 챕터 태그 스타일.

- 상단의 히어로, "오늘의 단어 학습" 버튼, "단어 추가"·"내 정보" 카드, 암기 모드 패널, 검색창은 그대로 둔다.
- **카드/리스트 보기 전환을 없앤다.** 단어는 항상 줄 하나로 보인다.
- 단어 목록은 **Day별 섹션**이다. 섹션 제목은 챕터 이름(`Day 1`)과 단어 개수다. 섹션 순서는 숫자 순서(`Day 2`가 `Day 10`보다 앞)이고 섹션 안의 단어 순서는 저장된 순서다.
- 한 줄 = **표제어 + 첫 번째 뜻(여러 뜻이면 `·`로 이어 한 줄)**, 수정·삭제 아이콘. 길면 한 줄로 줄임 표시한다.
- **암기 모드**의 "영어 가리기", "뜻 가리기" 스위치는 줄의 표제어와 뜻에 그대로 적용된다(눌러서 보기, 전체 정답 보기). "추가정보 가리기" 스위치와 줄별 정답 보기 버튼은 없앤다.
- **줄을 누르면** `/study?word=<단어 id>`로 이동한다. 가려진 표제어·뜻 부분을 누르면 이동하지 않고 그 부분만 보인다.
- **검색**: 표제어, 뜻, 동의어에서 찾고, 일치하는 단어가 있는 Day만 보여준다. 결과가 없으면 지금의 빈 상태 문구를 쓴다.
- 단어가 하나도 없으면 지금의 빈 상태 화면(추가 탭으로 안내)을 그대로 쓴다.

## 학습 탭

레퍼런스: 원본의 학습 카드 — 큰 세리프 표제어 카드, **번호 배지가 붙은 뜻 줄**(`.study-meaning`), **동의어 칩**(`.study-chip`), **예문 박스**(IN CONTEXT 패널), 진행률 막대와 하단 힌트 문구. 지금 앱의 `study.tsx`, `DetailPanel`의 스타일 값을 재사용한다.

- **진입**
  - 홈의 줄 → `/study?word=<id>`: 그 단어가 속한 **Day의 단어 목록**에서 그 단어부터 보여준다. 넘기면 같은 Day의 앞뒤 단어로 가고 끝에서 처음으로 돌아온다.
  - 하단 "학습" 탭과 "오늘의 단어 학습" 버튼 → 파라미터 없음: 전체 단어를 Day 순서(홈 목록과 같은 순서)로 첫 단어부터 보여준다. `prefs.activeChapter`가 `all`이 아니면 그 챕터만 보여준다(현재 동작 유지).
  - `word` 파라미터가 가리키는 단어가 없으면(삭제, 잘못된 주소) 전체 목록 첫 단어로 연다.
- **기본 화면**: 상단(뒤로가기, Day 라벨, `n / 전체`, 진행률 막대), 표제어 카드, 뜻 줄 목록(번호 배지 + 뜻). **뜻은 항상 보인다.** 암기 모드 설정은 학습 화면에 적용하지 않는다.
- **뜻 꾹 누르기**: 뜻 줄을 누르고 있는 동안 그 줄의 뜻 글자가 가려지고 그 자리에 **그 뜻의 동의어 칩**이 보인다. 손(또는 마우스 버튼, Space/Enter)을 떼면 뜻으로 돌아온다. 그 뜻의 동의어가 비어 있으면 누르는 동안 `등록된 동의어가 없어요`를 보여준다.
- **표제어 누르기**: 표제어 카드를 한 번 누르면 아래에 **예문 카드**가 열리고, 다시 누르면 닫힌다. 다른 단어로 넘기면 닫힌 상태로 시작한다.
  - 영어 예문은 표제어를 강조(굵게)해서 보여준다. 표제어가 영어 예문에 없으면 강조하지 않는다.
  - 한국어 해석에서 **맥락 뜻**(`exampleMeaning`이 해석에 있으면 그것, 없으면 뜻 목록에서 해석에 들어 있는 첫 표현)을 **회색 블록으로 가린다.** 그 블록을 꾹 누르는 동안 맥락 뜻이 굵은 글씨로 보인다.
  - 가릴 표현이 해석에 없으면 가리지 않고 해석을 그대로 보여준다. 예문이 없으면 `예문이 아직 없어요`를 보여준다.
- **넘기기**: 좌우 스와이프(영역은 지금과 같다), 마우스 휠(예문 카드가 닫혀 있을 때만), 키보드 좌우 화살표는 이번 범위에 넣지 않는다. 마우스 드래그 직후에 이어지는 클릭을 탭으로 세지 않는 기존 보호(100ms)는 유지한다.
- **꾹 누르기 구현 주의**
  - `Pressable`의 `onPressIn`/`onPressOut`으로 누르는 상태를 로컬 상태로 둔다(리듀서 상태가 아니다). 웹은 Space/Enter 키 다운·업이 같은 이벤트로 오는지 확인한다.
  - 브라우저의 글자 선택, 길게 누르기 메뉴(`contextmenu`), iOS 길게 누르기 콜아웃이 뜨지 않도록 선택을 막는다(`userSelect: none`, `-webkit-touch-callout: none`, `contextmenu` 취소).
  - 가볍게 탭해도 잠깐 깜빡일 수 있다. 눈에 거슬리면 누르기 시작을 약 120ms 늦춘다(브라우저 확인에서 판단).
  - 누르는 도중 손이 이동해 스와이프가 시작되면 누르기를 끝낸 것으로 처리해 동의어가 붙어 있지 않게 한다.
- **없애는 것**: 두 번 눌러 펼치는 동작, 뜻 선택 후 영영풀이·예문 패널(좌우 전환), 학습 카드의 칩 행(파생어·반의어 포함), `DetailPanel`, `ExamplePair`.

## 단어 추가·수정 폼

- 필드: **영단어***, **챕터**(선택 목록), **뜻***(줄바꿈), **뜻별 동의어**(여러 줄, 힌트 "뜻 순서대로 한 줄씩, 여러 개는 쉼표로"), **영어 예문**, **한국어 해석**, **예문에서 사용된 뜻**.
- 영영풀이, 반의어, 파생어, 유의어 칸은 뺀다.
- 검증 메시지·규칙은 그대로다: 영단어·뜻 필수(`영단어와 뜻을 입력해 주세요`), 영어·한국어 예문은 함께 입력(`영어와 한국어 예문을 함께 입력해 주세요`), 맥락 뜻은 한국어 해석 안의 표현(`사용된 뜻은 한국어 예문에 적힌 표현으로 입력해 주세요`).
- 동의어 줄이 뜻보다 많으면 남는 줄은 버리고, 적으면 `''`로 채운다.

## 서버 스펙에 미치는 영향 (코드는 1b에서)

교사 단어 테이블(`classroom_word`)과 업로드 형식의 **잠정안**을 이 구조에 맞춘다. 서버 저장소 스펙(`2026-09-30-classroom-wordbooks-design.md`) 갱신은 서버 PR 정리 뒤 별도 변경으로 한다.

- 컬럼: `definitions`, `antonyms`, `derived`, `related`를 뺀다. `synonyms`는 뜻과 같은 길이의 문자열 배열(JSONB)이다.
- 엑셀·CSV 열: `영어, 뜻, 챕터, 동의어, 예문, 한국어예문, 사용된뜻`. **동의어는 열 하나**이고 그 뜻을 가진 영단어를 쉼표로 적는다.
- **열린 질문(1b 확정 때 정한다)**: 한 단어에 뜻이 여러 개일 때 동의어 열을 어떻게 맞추나? 안 A: 단어 한 행에 뜻을 `;`로 나누고 동의어도 `;`로 뜻별 묶음을 나눈다(`nurture, develop; foster`). 안 B: 뜻마다 한 행씩 쓰고 단어를 반복한다(서버가 단어·챕터로 합친다). 앱 폼과 맞는 건 안 A다.

## 에러·엣지

- 저장된 단어가 비었을 때, 한 단어만 있을 때: 넘기기가 아무것도 깨지 않는다(기존 보호 유지).
- 뜻이 하나뿐인 단어, 뜻은 있지만 동의어가 모두 빈 단어, 예문만 있고 해석이 없는 옛 데이터: 모두 오류 없이 위 규칙대로 보인다.
- 옛 저장 데이터 변환에서 `synonyms`가 객체·숫자 등 이상한 값이면 `''`로 처리한다.
- 홈 줄 누르기로 학습 탭에 들어간 뒤 그 단어를 삭제하면(다른 탭 경유) 다음 진입에서 전체 목록 첫 단어로 연다.

## 테스트

- **Jest(순수 함수)**: `normalizeWord`의 옛 형태 변환(단어당 하나인 `synonyms` 문자열 → 첫 뜻, 배열 → 길이 맞춤, 사라지는 필드), `wordForm` 변환·검증(동의어 줄 맞춤, 기존 메시지), Day별 묶기·숫자 순 정렬, 검색(동의어 포함), 학습 상태(이동, 예문 열림/닫힘, 이동 시 닫힘), 맥락 뜻 가리기 조각 나누기(`exampleMeaning` 있음/없음/해석에 없음), 동의어 분리(쉼표, 공백, 빈 조각).
- **브라우저**: 홈 Day 목록과 줄 누르기 이동, 학습 탭의 꾹 누르기(동의어 보임·떼면 복귀·동의어 없는 뜻), 표제어 누르기로 예문 카드, 맥락 뜻 꾹 누르기, 스와이프·휠, 390px 폭, 모바일 에뮬레이션에서 글자 선택·메뉴가 뜨지 않는지, 옛 형태 데이터를 localStorage에 넣고 새로고침.

## 열린 질문

1. **홈 줄을 눌렀을 때 학습 범위**: 기본안은 그 단어가 속한 Day다. 전체 단어를 넘기게 하려면 바꾼다.
2. 위의 엑셀 동의어 열 형식(안 A/안 B).
3. 새 화면의 시각 디자인은 원본 프로토타입의 스타일을 재사용하며, 조은지 님의 별도 시안이 생기면 그에 맞춘다.
