# 학생 회원 탈퇴 (#47)

학생이 스스로 계정을 지운다. 서버 API는 `POST /api/me/withdraw` `{ "phoneLast4": "1234" }` → 204 (ssen-server).

## 동작
- 진입: 내 정보(`/account`)의 `회원 탈퇴` 카드 → `/withdraw`. 학생에게만 보이고, 눈에 덜 띄도록 `로그아웃` 카드 아래에 둔다.
- `/withdraw` 화면(`src/account/WithdrawScreen.tsx`, 라우트 `src/app/(main)/withdraw.tsx`)
  - 로딩이면 비우고, 서버에 연결할 수 없으면 `/account`, 비로그인이면 `/login`으로 보낸다. 교사 계정에는 입력칸 없이 "학생 계정에서 해요" 안내만 보여준다.
  - 학생에게는 지워지는 것(계정·북마크·내가 만든 단어)과 되돌릴 수 없다는 경고, 영향이 없는 것(선생님이 올린 단어·다른 친구), 같은 학교·이름으로 다시 가입할 수 있다는 안내를 보여준다.
  - 휴대폰 번호 뒤 4자리를 가려서(`secureTextEntry`) 입력해야 한다. 4자리를 다 채워야 `탈퇴하기`가 눌린다. `취소`는 서버 호출 없이 `/account`로 돌아간다.
- 제출 순서: 번호 검증 → `withdraw` → 이 기기 로그아웃(`logout()`) → 토스트 `탈퇴했어요` → 홈(`/`). 요청 중 중복 제출은 무시한다.

## 왜 이렇게 했나
- **확인을 화면으로 한다.** 웹에서는 `Alert`가 동작하지 않아서, 별도 확인 화면과 번호 입력으로 실수로 지우는 일을 막는다.
- **번호가 틀리면 403이다(401이 아니다).** 앱은 401을 로그인 만료로 보고 토큰 갱신·로그아웃을 시도한다. 틀린 번호로 로그아웃되지 않도록 서버가 일부러 403을 쓴다. 5번 틀리면 5분간 429(서버 문구 그대로 표시).
- **성공한 뒤에만 로그아웃한다.** 틀린 번호·서버 오류에서는 로그인을 유지한다. 틀린 번호(403) 뒤에는 입력칸을 비운다. 탈퇴한 계정의 토큰은 서버가 모두 401로 처리하므로 `logout()`은 이 기기의 토큰만 지운다.
- 탈퇴 후에는 로그아웃 상태라 `refreshUser`·북마크 `reload`를 부르지 않는다. 이 기기의 로컬 단어장·북마크(비로그인용 AsyncStorage)는 건드리지 않는다.

## 서버에서 지워지는 것
계정, 북마크, 학생이 만든 개인 단어. 교사가 올린 수업 단어와 다른 학생은 그대로다. 같은 학교·이름으로 다시 가입할 수 있다.

## 오류 처리
| 상황 | 표시 |
| --- | --- |
| 4자리 미만 | 버튼 비활성(제출 시에도 `휴대폰 번호 뒤 4자리를 숫자로 입력해 주세요`) |
| 403 | 서버 메시지: 번호가 올바르지 않아요. (입력 비움) |
| 429 | 서버 메시지: 시도 횟수를 초과했어요. 5분 뒤에 다시 시도해 주세요. |
| 네트워크·기타 | 클라이언트 기본 문구, 그 외 요청에 실패했어요 |
| 로그인 만료 | 로그인이 만료됐어요. 다시 로그인해 주세요 |

## 확인할 것
- 개인정보 처리방침(탈퇴 시 삭제 항목·보관 기간)에 반영이 필요한지는 사람이 확인한다.
- 교사 계정의 탈퇴는 서버가 403으로 거절하며, 앱은 안내만 보여준다.
