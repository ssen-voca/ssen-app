# 교사: 수업 관리 (#45)

교사가 수업의 이름, 참여 받기 여부, 참여 코드, 학생, 삭제를 한 화면에서 관리한다. 서버 API는 ssen-server develop의 `GET/PATCH/DELETE /api/teacher/classrooms[/{id}]`, `POST .../{id}/code`, `GET .../{id}/students`, `DELETE .../{id}/students/{studentId}`.

## 화면 (`/manage-classes`)
- 진입: 내 정보의 교사 카드 `수업 관리`. 접근 제한은 `/manage-words`와 같다(로딩 중 빈 화면, 비로그인 `/login`, 교사가 아니면 `/account`).
- 수업 목록은 라디오 행이다. 행마다 수업 이름과 `학생 {n}명 · 참여 받는 중` 또는 `참여 닫힘`.
- 수업을 고르면 아래에 상세가 펼쳐진다: `이름`(수정), `참여`(열기/닫기), `참여 코드`(복사·다시 만들기), `학생 {n}명`(내보내기), `수업 삭제`.
- 수업을 바꾸면 상세를 통째로 새로 만들어 이전 수업의 편집·확인·늦은 응답을 모두 버린다. 서버 호출은 한 번에 하나만 보내고, 오류는 해당 섹션 안에 서버 메시지로 보여 준다.

## 참여 닫기와 코드
- 닫힌 수업은 새 학생이 코드로 들어올 수 없다(서버가 403과 안내 문구를 주고 참여 화면이 그대로 보여 준다). 이미 들어온 학생은 그대로다.
- 코드를 다시 만들면 옛 코드는 즉시 쓸 수 없고 이미 들어온 학생은 그대로다. 코드 복사는 웹에서만 보이고, 클립보드를 쓸 수 없으면 조용히 넘어간다.

## 확인 절차
- `Alert`는 웹에서 동작하지 않아서 코드 다시 만들기·학생 내보내기는 화면 안의 인라인 확인(`#44`와 같은 패턴)을 거친다.
- 학생 내보내기는 소속만 해제한다. 계정과 북마크는 남고 같은 참여코드로 다시 들어올 수 있다.
- 수업 삭제는 단어와 학생 북마크가 사라지고 되돌릴 수 없어서, 한 번 더 묻는 대신 수업 이름을 정확히 입력해야 버튼이 켜진다(실수로 눌러도 지워지지 않는다).
